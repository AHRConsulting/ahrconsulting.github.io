LinqExtensions

View source

Namespace: Ahr.Foundation

Inheritance: object

LINQ query-syntax support for Result<T>, Result<T, TError>, and Option<T>.
public static class LinqExtensions

Remarks

Select maps a success value and SelectMany chains a dependent operation, so query syntax such as from user in FindUser(id) from order in LoadOrder(user) select order.Total short-circuits on the first failure exactly as the equivalent Bind chain does. Prefer Map and Bind for short chains; query syntax suits pipelines where later steps need values bound earlier. Query syntax is synchronous only.
