AHR Assurance API reference

Ahr.Assurance.Core

  • AssuranceRunResult class
    The result of a run of scenarios.
  • BusinessContext class
    What a group of scenarios protects: its capabilities, the outcomes people expect, the rules that must hold and the risks guarded against.
  • BusinessContextBuilder class
    Builds a BusinessContext. Each call returns a new builder, and the original stays unchanged.
  • BusinessItem class
    A named business item with a stable ID, such as a capability, outcome, rule, risk or objective.
  • BusinessRule class
    A rule that must hold.
  • Capability class
    Something the system lets people do.
  • ExpectationResult class
    The verdict on one step, with the reason and, for a check, the expected and actual values.
  • ExternalReference class
    A link to where the work is tracked, such as a ticket. The provider is free text.
  • Objective class
    A goal the work serves.
  • Outcome class
    A result people expect from a capability.
  • Risk class
    Something that could go wrong and that the scenarios guard against.
  • ScenarioResult class
    The result of one scenario.
  • StepParameter class
    An input a step records for tracing, through WithValue, written with the invariant culture.
  • StepResult class
    The result of one step in a scenario.
  • AssuranceStatus enum
    The verdict on a step, scenario or run.
  • StepKeyword enum
    The keyword a step is shown with in reports.
  • StepKind enum
    The phase a step belongs to.

Ahr.Assurance.Execution

  • Attach class
    Adds files and data to the evidence of the scenario step that is currently running, or to the scenario between steps.
  • Scenario class
    A single-use inline composition over Fact-local variables. The caller owns captured resources.
  • ScenarioAction<TContext> class
    A named, reusable piece of setup or operation work over a context, for Given/When and their action And steps.
  • ScenarioExpectation<TContext> class
    A named, reusable check over a context, for Then and its expectation And steps.
  • ScenarioSteps<TContext> class
    Optional authoring helper for reusable steps over a typed context. Definitions receive fresh execution state from the runner; do not capture live contexts in shared steps.
  • Scenario<TContext> class
    An immutable composition of named, reusable steps over a fresh typed context.
  • SharedStepExtensions class
    Steps written for an interface or base type, used in a scenario whose context implements or derives from it. A context that doesn't fails to compile. The context must be a class, so a step's changes reach the scenario's own context.
  • AttachmentKeep enum
    When an attachment is kept in the evidence.

Ahr.Assurance.MSTest

  • AssuranceAssert class
    Explicit multi-scenario verification entry point.
  • AssuranceMSTestConfiguration class
    Configures AHR Assurance for an MSTest test project.
  • InlineScenarioExtensions class
    Verification for local-variable scenarios, using the standard verification lifecycle.
  • ScenarioVerificationExtensions class
    Executes and verifies scenarios in MSTest tests.

Ahr.Assurance.NUnit

  • AssuranceAssert class

  • AssuranceNUnitConfiguration class
    Configures AHR Assurance for an NUnit test project.
  • InlineScenarioExtensions class
    Verification for local-variable scenarios, using the standard verification lifecycle.
  • ScenarioVerificationExtensions class
    Executes and verifies scenarios in NUnit tests.

Ahr.Assurance.Playwright

  • AssurancePlaywright class
    Attaches a page's screenshots and trace to the evidence of the scenarios verified while a capture is in scope.
  • PlaywrightCaptureOptions class
    What a Playwright capture attaches to the evidence.
  • ScreenshotCapture enum
    When to attach a screenshot of the page.
  • TraceCapture enum
    When to attach the Playwright trace of a scenario.

Ahr.Assurance.Reporting

  • AssuranceArtifact class
    A file an evidence sink wrote for a verification.
  • AssuranceReport class
    Run evidence, which may be partial when execution diagnostics are present.
  • AssuranceResults class
    The verification evidence in one results folder, such as a run folder: its top-level JSON files, in file name order.
  • AssuranceVerificationResult class
    The outcome of a verification: its run and the files its evidence sinks wrote.
  • EvidenceAttachment class
    Portable attachment metadata. Content is resolved separately; never serialized as live objects.
  • EvidenceDeliveryContext class
    Where and how a sink delivers a verification's evidence.
  • EvidenceDeliveryResult class
    What a sink delivered for one verification.
  • HtmlReportSinkOptions class
    Options for the HTML sink from Html(HtmlReportSinkOptions?).
  • JsonReportSinkOptions class
    Options for the JSON evidence sink from Json(JsonReportSinkOptions?).
  • ReportDiagnostic class
    A problem met while running a verification or delivering its evidence.
  • ReportOptions class
    Immutable options for running verifications and delivering their evidence.
  • ReportSinks class
    Built-in verification outputs. Explicit sink lists replace the defaults.
  • VerificationEvidence class
    One captured verification, independent of its delivery destinations and test framework.
  • IAssuranceEvidenceSink interface
    An output that receives each verification's evidence, such as the built-in ones in ReportSinks.
  • AssuranceTextVerbosity enum
    How much detail a verification's text in the test output shows.
  • VerificationExecutionState enum
    How a verification's execution ended.
